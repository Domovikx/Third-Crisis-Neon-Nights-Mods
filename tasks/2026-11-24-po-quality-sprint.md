# [2026-11-24] Спринт качества PO: до «зачётного» уровня, с акцентом на rich-разметку

Статус: READY (этап 1 выполняется сабом; остальные — по порядку, GPU-очередь одна)

## Цель

Довести все 10 PO до состояния, когда остаток дефектов — только слой «нужен
носитель», и зафиксировать это измеримо, а не на вкус.

## Зачётные критерии (числа, не слова)

1. **rich**: у каждой переведённой строки с `rich_text` есть `rich_translation`
   с теми же тегами; `PO adjacency` = 100 %; `.dat` ↔ POT по ключам = 0 расхождений.
2. **судья**: полный прогон (не выборка) по каждому языку, флагов ≤ 1 %
   (сейчас 0,75–3,3 % на выборке; 268 флагов из 366 остались после первого пасса).
3. **механика**: 0 пустых, 0 validate-дефектов, имена только по канону,
   0 утечек подписи спикера в тексте, 0 чужой письменности.
4. **термины**: один канон на язык из `tmp/glossary-proposal.md` (23 термина, 1 067 строк).
5. `npm run verify` зелёный, все гейты (rich, имена, письменность) в нём.

## Этапы

1. **rich_translation** (саб, идёт): бэкфилл 2 374 × 10, поддержка в
   `translate_local`/`rich_pass`, сидинг в `po:update`, adjacency-гейт + `.dat ↔ POT`.
2. **Механика без модели** (CPU, быстро): ja 9 строк с арабской «ف»; 310 утечек
   спикера (pt 129, es 96, it 60, fr 19, ru 6); имена по канону (zh Lio 42,
   ja Jaime 25, it Mira/Guarda, Rungar/Rugnar).
3. **Термины**: применить канон `tmp/gloss_canon.json` — замена целых вхождений в
   `msgstr`, затем пере-суд затронутых строк; не улучшилось — откат.
4. **Полный прогон судьи** по 10 языкам (не выборка) — финальные проценты.
5. **Добор флагов**: `improve` по ключам из PO → пере-суд → приёмка
   (`improve_verdict`), повторять до плато.
6. **Отчёт «остаток носителю»**: список строк, где модель и правила бессильны.

## Ограничения

- GPU один слот: пассы и судья идут строго последовательно, без параллельных
  LLM-прогонов.
- Один писатель на язык: пока идёт `improve`/бэкфилл, никто другой не пишет тот же PO.
- Данные правятся только по ключу (`msgctxt \u0000 msgid`), не по индексу отчёта.
- Приёмка улучшений — только через повторный суд; «стало красивее» не аргумент.
