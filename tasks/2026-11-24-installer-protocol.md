# [2026-11-24] Протокол установщика NeonTranslatorDX: один UI, три способа установки

Статус: READY (меню и установщик — после PO-спринта; сейчас фиксируем договорённости)

## Цель

Один и тот же интерфейс установки в трёх исполнениях, без копипаста:

1. **exe (Tauri 2)** — полный: находит Steam, ставит, удаляет, манифест, обновления.
2. **браузер** (без скачивания) — страница открывается, пользователь выбирает папку игры,
   страница пишет файлы мода через File System Access API.
3. **7z вручную** — архив с той же раскладкой, ставится распаковкой.

## Как переиспользовать UI (без копипаста)

Tauri 2 = **Rust-бэкенд + обычный web-frontend**. Значит один и тот же React-билд
работает и в окне Tauri, и как статический сайт. Разница — тонкий адаптер:

```text
installer-ui/                # React 19 + StyleX, один код
  src/ui/…                   # экраны: установка (все перевода сразу), прогресс, удаление
  src/platform/index.ts      # выбор адаптера по среде
  src/platform/tauri.ts      # invoke('install', …) → Rust
  src/platform/browser.ts    # showDirectoryPicker + File System Access API
```

- `isTauri()` определяет среду в рантайме, экраны не знают, где они живут;
- типы операций (`install`, `uninstall`, `verify`, `progress`) — общий контракт;
- сборка: `vite build` → `dist/` (веб) и тот же `dist/` вшивается в Tauri-бандл;
- 7z собирается из того же манифеста файлов — третий артефакт, не третий UI.

Ограничения браузера (честно, в UI показываем): нет автопоиска Steam (пользователь
выбирает папку руками), нельзя запускать игру и лезть в реестр, API работает в
Chromium (Edge/Chrome; Firefox/Safari — только 7z).

## Раскладка (одна папка мода)

```text
<игра>/dwmapi.dll                  # единственный файл вне папки
<игра>/NeonTranslatorDX/
  NeonTranslatorDX.dll
  fonts/*.ttf
  patch_<lang>.dat
  active_lang.txt
  install-manifest.json            # файл, размер, sha256 — для удаления/обновления
```

Удаление = манифест + папка + лоадер; чужие файлы не трогаются.

## Что ставим: все переводы сразу

Выбора языков в установщике НЕТ — это не аудио-паки, где язык выбирают по вкусу.
Пакет текстов один: `patch_ru.dat … patch_it.dat` (10 языков) кладутся все сразу,
а переключение языка остаётся в меню игры в рантайме. Отдельные пакеты появятся
только если/когда будет озвучка — тогда и вернём галочки языков для голосов.

## Меню в игре (после PO)

Полноэкранное, по образцу TSSR (`zzz_ui.rpy`): сетка 10 языков, индикатор «пак есть /
только текст», строки статуса «Текст: N из M», «Озвучка», кнопки «Применить/Отмена»,
подписи нижней панели. В TCNN — UGUI + TextMeshPro, дизайн-токены отдельным конфигом,
CJK-кегли (+2 zh/ja, +1 ko) и фолбэк шрифтов. Браузер в игру не внедряем.

## Приёмка

- `clean_room diff` после установки: `изменено: 0`, добавлено только `dwmapi.dll` и
  `NeonTranslatorDX/…`; после `uninstall` — diff с чистым снимком пустой.
- Steam «Проверить целостность» не перекачивает ни одного файла игры — ни после
  установки, ни после удаления.
- Браузерный режим: тот же результат файлов, что exe (сверка sha256 по манифесту).
- Один UI: переключение режима не требует второй верстки (код-гейт: два адаптера,
  один набор экранов).

## Этапы

1. Протокол и раскладка (этот файл) — сделано.
2. Меню в игре (UGUI) — после PO.
3. `installer-ui` + Tauri-адаптер + Rust-команды (install/uninstall/verify).
4. Браузерный адаптер (File System Access API) на том же билде.
5. Сборка 7z из манифеста + README.
6. E2E: чистая игра → установка → скрин меню → удаление → diff пустой.
7. Мод-менеджер (Vortex/FOMOD) — отдельная задача, после релиза.
