# [2026-11-21] Портировать инструменты PO: `po_update`, `prefill_po`, `find_source`

Статус: READY

## Задача от пользователя

Часть общей задачи: «максимально запускаем миграцию на ts mts вместо питона».

## Цель

Обслуживание PO-файлов (перенос переводов в новый POT, предзаполнение, поиск источника строки)
работает на TS, без Python. Это ежедневные операции при апдейте игры, поэтому они важнее
разовых скриптов.

## Контекст

- `po_update.py` (151 строка) — перенос `msgstr` в новый `template.pot` по ключам, точный
  перенос / ретаргет / новые пустые записи. Опирается на `po_file.py` (уже портирован).
- `prefill_po.py` (221) — предзаполнение пустых `msgstr` (в т.ч. авто-триаж ассетов и мусора через
  `text_filters`).
- `find_source.py` (62) — поиск источника строки по дампу; импортирует `potgen`.
- Все три пишут PO. Запись обязана быть **атомарной** (`.part` → rename): обрыв процесса не должен
  обнулять файл перевода.

## Что сделать

1. Прочитать три Python-модуля и их тесты (`po_update.test.py`, `potgen.test.py`-часть,
   `prefill_po` логика).
2. Вопросы ресёрча:
   - где взять общий «atomic write» хелпер, чтобы не дублировать его в каждом модуле;
   - как формализовать «точный перенос / ретаргет / новый» без изменения поведения;
   - нужен ли `find_source` вообще, если `#: refs` больше не пишутся в POT (проверить по коду и
     по факту использования).
3. Реализовать на `.mts` с тестами; `find_source` — после `potgen` (см. задачу порта POT).
4. Паритет: прогнать Python и TS на копии реальных `po/` (в `tmp/`) и сравнить результат
   байт-в-байт после нормализации EOL.
5. Удалить `.py` из нового дерева, обновить `SKILL.md`.

## Приёмка

- [ ] `node .../po_update.mts` переносит переводы в новый POT: результат совпадает с Python
      на тех же входах (diff пуст после нормализации EOL)
- [ ] `prefill_po` даёт те же заполнения, что Python
- [ ] Запись атомарная: при прерывании (эмуляция — исключение посреди записи) исходный файл цел
- [ ] Тесты на: пустой PO, PO без заголовка, дубликаты msgid, запись с `\n` и кавычками
- [ ] `npm run typecheck`, `npm run lint`, `npm test` зелёные
- [ ] `.py` удалены из нового дерева, `docs/migration.md` обновлён

## Вне рамок

- Массовый перевод (это `translate_local`, отдельная задача).
- Изменение формата PO/флагов.
