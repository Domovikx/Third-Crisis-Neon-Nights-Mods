## 3. Сопоставление клип ↔ строка

### 3.1. Метод

1. Имя клипа = текст реплики (пунктуация заменена на `_` для файловой системы); у части
   клипов есть префиксы `NN-` и `VA<Name> - NNN - `.
2. Нормализация обеих сторон: снять rich-теги (`<i>`, `<color=…>`, `_i_`, `_b_`,
   `_color=…_`), апострофы, пунктуацию, регистр; схлопнуть повтор слов (`didnt didnt`).
3. Три уровня: exact → prefix (клип/строка — префикс другого, ≥4 слов) → fuzzy
   (пересечение слов ≥ 0,8, ≥4 слов). Fuzzy нужен там, где актёр сказал чуть иначе,
   чем в тексте (например, «seem to be» вместо «seem to take security lightly»).
4. Атрибуция персонажа: `VA<Name>` → персонаж из префикса; иначе явный `speaker:` POT;
   иначе пресет из `raw_strings` (`<Name> Dialogue Presets`); для мыслей в скобках —
   Зои; иначе имя диалогового объекта (`Salon_Max_*` → Max, `Novas …` → Nova).

| -------------------------------------- | -----------------------------------------------------: |
| Клипов-кандидатов (речь + тейки)       |                                                     99 |
| Из них сопоставлено со строкой корпуса |                                                 **83** |

## 9. Эмоции: план (без запуска)

### 9.1. Как это сделано в TSSR

- `#. emotion:` в `po/template.pot`, ключ — `uid = md5(msgid)`; тон — **по-английски,
  2–6 слов, состояние диктора**, не приказ и не пересказ текста.
- `emotion_tag.mts`: эвристика `RULES` или локальная LLM (OpenAI-compatible
  `/v1/chat/completions`), черновик → `tmp/emotions_tagged.json`, резюмабельно,
  чекпоинт каждые 200 строк.
- `potgen --emotions` кладёт слой `#. emotion_new:` (старый `emotion` не перетирается).
- Аудит `npm run emotion:audit`: пусто, кириллица/CJK, `none`, >6 слов, 1 слово,
  без заглавной, кавычки; однородность (топ-тон, доля, % «один раз»).
- Судья-выборка — опционально, LLM-балл «тон подходит строке/спикеру/сцене».

### 9.2. Что адаптировать для TCNN

1. **Ключ**: `md5(msgid)` или сам `msgid`; в TCNN `uid` нет. Для первого шага — sidecar
   `config/voice-emotions.json` (`msgid` → тон), **без правки POT**: Rust `potgen`
   пересобирает POT из дампа, и добавлять туда слой — отдельное решение (золотой POT
   изменится). Sidecar читает будущий voice-пайплайн; POT не трогаем.
2. **Объём**: 7 324 строки (не 68k), один тон на уникальный EN-текст; языки не множатся.
3. **Правила**: те же 7 правил TSSR; запрещено шаблонить один тон на тысячи строк
   (в TSSR был инцидент «26 % Curiously observing»).
4. **Стоны**: M0/M1 не размечаем (не озвучиваются); M2 — размечаем, это обычные реплики.
5. **Аудит**: портировать проверки формата и однородности; сцен/арок в TCNN нет —
   контекст брать из соседних строк сцены (объект диалога) и `speaker`.

### 9.3. Какая LLM доступна сейчас

Проверка `node scripts/llm_backend.mts status` (TSSR, только проба портов, без запуска):

| Бэкенд    | Порт | Статус   | Модель                                   |

| Colibri   | 8000 | **down** | qwen3.6-colibri                          |

### 9.4. Оценка времени

**1–3 ч**; плюс аудит 0,3–0,5 ч. Первые 100 строк — замер и калибровка промпта.
Запускать **только когда Vox не идёт** (GPU/VRAM).

## 12. Риски

1. **Юридический (главный).** Клонирование голоса актёра из коммерческой игры и
   распространение мода — это право на голос/внешность (right of publicity) и лицензия
   Anduo Games. Бесплатный мод не снимает риск: возможен DMCA/жалоба, особенно на Nexus.
   Варианты: (а) voice design без клонирования — безопаснее; (б) клон только локально,
   без распространения; (в) разрешение разработчика/актёра; (г) наём актёров.
   **Решение — за владельцем**, до генерации.
2. **Качество.** У 19 персонажей нет оригинального голоса; voice design даст «похожий
   типаж», но не того же актёра. Смешение клонов и синтетики в одной сцене слышно.
3. **Данные.** 96 % объектов `level/sharedassets` — `read_failed`; имена клипов там
   не видны. Возможны неучтённые голоса (Leona/Jay). POT-порядок не равен порядку игры
   (в первых 80 строках оказались мысли из главы 3).
4. **Мусор в POT.** Две «строки» салона — режиссёрские пометки; если озвучивать корпус
   вслепую, они попадут в озвучку. Нужна чистка/фильтр.
5. **Технический.** В TCNN нет voice-пайплайна (мод текстовый): нужен рантайм-плеер,
   ducking оригинала, раскладка файлов. Это отдельная задача, не входит в ресерч.
6. **GPU.** Vox 17,6 ч и LLM-разметка несовместимы по VRAM; планировать окна.
