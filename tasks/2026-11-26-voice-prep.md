## 1. Требования VoxCPM2 к рефам (цифрами)

Локально: `C:/tools/voxcpm2` (пакет `voxcpm 2.0.3`, `models/VoxCPM2`); официально —
[Usage Guide](https://voxcpm.readthedocs.io/en/latest/usage_guide.html),
[Cookbook](https://voxcpm.readthedocs.io/en/latest/cookbook.html),
[README](https://github.com/OpenBMB/VoxCPM).

| Параметр        | Значение                                                                  |
| --------------- | ------------------------------------------------------------------------- |
| Длительность    | практический диапазон **5–30 с**; минимум — «правило 5 секунд»            |
| Формат          | любой torchaudio/librosa: **WAV, FLAC, MP3, OGG**                         |
| Частота входа   | любая → внутри **16 кГц** (`audio_vae.sample_rate = 16000`)               |
| Каналы          | любые → **mono** (`librosa.load(..., mono=True)`)                         |
| Частота выхода  | **48 кГц** (`out_sample_rate = 48000`, AudioVAE V2)                       |
| Чистота         | «чем чище, тем лучше тембр»; денойзер опционален и **может менять голос** |
| Транскрипт      | не нужен для cloning; нужен только для **Hi-Fi** режима                   |
| Контекст модели | 8 192 токена при 6,25 Гц → 30 с рефа ≈ 188 токенов (не проблема)          |
| VRAM / RTF      | ~8 ГБ / ~0,30 на RTX 4090 (10 шагов)                                      |

Выводы, которые важны для нас:

- **24 кГц mono — с запасом**: модель всё равно пересчитывает реф в 16 кГц;
- реф **структурно изолирован** (`ref_audio_start` … `ref_audio_end`), модель его
  не «продолжает» — поэтому длина рефа сама по себе не вызывает дрейфа голоса;
  дрейф в документации связан с **длинным целевым текстом** и высоким `cfg_value`;
- **5–30 с**: 20–25 с — верх разрешённого, а не вредного; но длинный реф из
  разных сцен размывает тембр, поэтому все варианты одного персонажа собраны из
  одной сцены;
- официального «оптимума» документация не даёт — его и меряем A/B/C.

Полный разбор (что делает код, почему 5–30, где дрейф, Hi-Fi лазейка) —
`docs/voice-refs.md`.

2. **Lio: длинного варианта нет.** Весь корпус — 5 клипов, 10,45 с. «C» (20–25 с)

3. **Rosie: тейки — не речь.** Акустика: 11–12 % вокализованных кадров (у речи

   при пике −20 дБ), спектр — диффузная низкочастотная энергия без формант.
   Ни один тейк не сопоставлен со строкой POT по тексту. Сделан один контрольный
   `RosieX.wav`, чтобы убедиться за 5 секунд: **для клонирования диалога Rosie
   не годится**, нужен voice design или актёр.
4. **Пойман баг до генерации:** в первой сборке MaxB/MaxC в склейку попали две

   (188 → 203–254 Гц). Урок: состав рефа проверять по `speaker:` из POT, а не по
   сцене.
5. **Фон в сценах есть, музыки не слышно.** Клипы салона (Max) и сцены Rosie —
   stereo, но каналы идентичны (side/mid −50…−64 дБ); SNR 12–60 дБ. Признаков

## 4. Что проверить завтра первым

Порядок (≈10 мин GPU, если гнать всё: 45 генераций × 5–14 с по замеру демо):

1. **Три фразы × 2–3 рефа, не больше.** Фразы короткие и разные по тону (у всех
   трёх есть оригинальный клип в `tmp/voice-refs/` — для сравнения «оригинал vs
   клон»):
   - нейтральная мысль: «His pants are unzipped…» (Зои, клип 71);
   - вопрос: «How do you like my new arrow tattoos?» (Lio, клип 05);
   - эмоциональная: «U-Uhm… maybe a uh… a penis…» (Max, клип 62).
2. Одинаковые параметры на все прогоны: `cfg_value=2.0`, `inference_timesteps=10`,
   одна и та же эмоция из POT, `denoise=False` (рефы уже вычищены).
3. Слушать в порядке: **тембр** (похож на оригинальный клип) → **стабильность
   внутри реплики** (нет «прыжков») → **интонация/эмоция**.
4. Решение: если B не хуже A и лучше C по стабильности — брать **B**.
   Если B и C одинаковы — брать B (короче = дешевле по контексту).
5. Отдельно и первым делом: **Nova** — послушать `NovaB.wav` и клип 2,04 с
   (`tmp/voice-refs/zoeyeatingoutnova/147-01-Staring Are we 0.wav`): один ли голос.
   И **Rosie** — 5 секунд `RosieX.wav`, чтобы закрыть вопрос «это дыхание?».
6. Если B «мало тембра» — попробовать Hi-Fi режим (нужен транскрипт, а тексты
   клипов у нас есть): `prompt_wav_path` + `prompt_text` + `reference_wav_path`.

Порядок не запускать одновременно с LLM: VoxCPM2 занимает VRAM (~8 ГБ), а
Strata/LM Studio — свою.

## 5. Рекомендация: какой длины реф брать

**B, 15–18 с.** Обоснование:

- официальный диапазон 5–30 с, B — его середина, а не край;
- в 15–18 с уже 3–5 разных фраз, то есть достаточно тембра, но меньше разброса
  просодии, чем в C (20–25 с);
- A (10–12 с) — контроль «как в TSSR»; если A и B неразличимы, брать A (меньше
  контекста);
- C (20–25 с) — проверка гипотезы «длиннее = точнее»; ожидание: тембр не
  улучшится, а стабильность может просесть;
- Lio — только B (11,05 с): весь корпус 10,45 с, короче некуда;
- Rosie — реф не годится, нужен voice design.

Цифры для отчёта: реф 15–18 с = 94–113 токенов из 8 192 доступных, то есть
длина рефа на контекст не влияет; выбор чисто по качеству клона.
