# [2026-11-21] Спайк: пробная озвучка реплик поверх студийной (с ducking)

Статус: READY

## Задача от пользователя

«по поводу озвучки, мы можем конечно тестово попробовать наложить поверху что-то сгенерированное
нашими Vox, но только реплики, потому что там студийная озвучка и скорее всего её просто придётся
накладывать и работать со звуком, то есть что-то во время реплики приглушать и после реплики
восстанавливать, хм... там надо будет попробовать, может и получится, тогда пользователю нужно
будет бегунки звука вынести насколько глушить оригинал во время наших фраз. И там сложное описание
эмоций и хз справится ли Vox, может ДЭМО попробовать...»

## Цель

Ответить на вопрос «имеет ли смысл» малой кровью: на 10–20 репликах одной сцены проверить, что
(а) мы можем поймать момент старта реплики, (б) можем приглушить студийный голос и восстановить,
(в) VoxCPM2 вытягивает эмоции настолько, что это не портит впечатление.

Результат — вердикт go/no-go с числами, а не «вроде работает».

## Контекст (проверено по дампу 2026-11-21)

- Аудио в игре есть: `AudioClip` в `sharedassets*` и анимационных бандлах, формат `.fsb`
  (FMOD sample bank). Имена — SFX/музыка (`Penetration_VeryWet_2_005`, `Smear_3_Long_0030`).
- `AudioSource` есть, с полями `OutputAudioMixerGroup` (`path_id` 10688), `m_Volume`, `Loop`,
  `m_audioClip` — то есть звук идёт через **AudioMixer-группы**, а значит приглушение по группе
  технически возможно.
- Многие `AudioClip` в дампе помечены `extract_failed` — дампер их не декодирует. Значит связь
  «строка → студийный клип» из дампа не достаётся, её надо ловить в рантайме.
- Рантайм уже умеет ловить момент появления текста (scan-and-replace на отрисовке Canvas) — это
  готовый триггер для старта нашей реплики.
- Озвучка — отдельный эксперимент; основной мод остаётся **текстовым** (см. `AGENTS.md`).

## Что сделать

1. Ресёрч по коду игры (дамп, C#-исходники мода, PlayMaker FSM):
   - как FSM запускает реплику (действие PlaySound / AudioSource.Play?) и есть ли детерминированная
     связь «строка текста ↔ клип» (например, по имени `line_XXX` или по индексу в DialogueHistory);
   - какая AudioMixer-группа несёт голос, а какая музыку/SFX (найти микшер и группы);
   - совпадает ли старт текста и старт студийного клипа (если нет — нужна задержка/подстройка).
2. Ресёрч по нашей стороне:
   - как VoxCPM2 ведёт себя на эмоциональных репликах этой игры (сравнить 5–10 фраз разных типов:
     нейтральная, ярость, шёпот, кульминация);
   - какой уровень задержки приемлем (старт клипа относительно появления текста).
3. Минимальный эксперимент (демо, без полного пайплайна):
   - 10–20 реплик одной сцены, русский;
   - BepInEx-плагин/патч: при появлении строки — играть наш клип, приглушать группу голоса
     на N дБ, по окончании — восстанавливать;
   - регулятор «насколько глушить оригинал» в настройках мода (0…−30 дБ), применяется на ходу.
4. Замерить и записать: рассинхрон (мс), артефакты, как звучит наложение, что с эмоциями.

## Эмоции и структура демо

Эмоции — **метаданные в POT**, как в текущем репозитории TSSR: строка `#. emotion:` рядом с
записью `msgid`, ключ — сам текст (уникален). Это даёт:

- один источник тона для всех языков (тон не зависит от перевода);
- сброс тона при изменении текста (текст изменился — эмоцию надо перепроверить);
- генератору (`voice_batch`) не нужно ничего знать про игру: читает `#. emotion:` по uid.

Демо-набор (минимум для вердикта):

- 10–20 реплик одной сцены, разные по типу: нейтраль, ярость, шёпот, страх, кульминация;
- для каждой — «ожидаемый тон» одной строкой (что должно слышаться);
- результат: клип + оценка «попал / мимо / неоднозначно» по каждому;
- отдельно: 2–3 **длинные** реплики (проверка дрейфа голоса внутри клипа).

Разметку тона делаем вручную для демо (автоматическая разметка — отдельная задача, и она
осмысленна только после вердикта «go»).

## Приёмка

- [ ] На демо-сцене наша реплика стартует вместе с текстом; рассинхрон замерен и указан в мс
- [ ] Студийный голос приглушается и восстанавливается; слышимой «дыры» после реплики нет
- [ ] Регулятор глубины приглушения работает на ходу и сохраняется
- [ ] 10–20 реплик озвучены; в задаче — список фраз с оценкой «норм / мимо» по эмоциям
- [ ] Явный вердикт: go / no-go, с условиями пересмотра
- [ ] Если go — отдельные задачи: пайплайн генерации, формат упаковки, UI-настройки
- [ ] Текстовая часть мода не затронута (регрессий нет)

## Вне рамок

- Автоматическая генерация эмоций для всех фраз (это уже следующий этап).
