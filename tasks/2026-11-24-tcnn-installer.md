# [2026-11-24] Установщик и распространение мода TCNN: одна папка, два варианта, чистый аннинсталл

Статус: READY (этап «чистая переустановка игры» — BLOCKED до отдельной сессии с владельцем)

## Задача от пользователя

«хотелось бы не менять файлы игры вообще… иметь возможность ставить и удалять мод
полностью включая папки чтобы мусора не оставалось. продумывать будем два варианта
через наш инсталлятор и ручной вариант… файлы максимально собрать в нашу папку с
модом - так будет проще удалять потом».

Ориентир — установщик TSSR (`The-Survival-of-Sarah-Rose-Mods`):
`patches/ai-voice-pack/tools/build/installer/install.cmd` + `voice_install.ps1` +
`worker.ps1` (Steam-библиотеки, атомарный staging→swap, .7z-паки) и
`installer/` (Tauri: Rust + TS/React, E2E на Playwright).

## Цель

Один самодостаточный набор установки: **вся нагрузка в одной папке мода**, в игре —
только один неизбежный файл-лоадер. Удаление = удалить папку и лоадер, без следов.
Два пути: наш установщик (двойной клик) и ручной (распаковать архив).

## Контекст (замер 2026-11-24)

Как ставимся сейчас (`deploy.mts`):

- `<игра>/dwmapi.dll` — прокси-лоадер (C, `build-translator/source/dwmapi_proxy.c`),
  грузит рантайм по **жёстко прописанному** пути
  `<игра>/..._Data/Managed/NeonTranslatorRuntime.dll` через `mono_domain_assembly_open`;
- `<игра>/..._Data/Managed/`: `NeonTranslatorRuntime.dll`, 3 шрифта
  (`RobotoCondensed-Regular`, `NotoSansSC`, `NotoSansJP`), `patch_<lang>.dat`,
  `active_lang.txt`;
- исполняемые файлы и ассеты игры не редактируются — только добавляются файлы;
- деплой: 148–186 мс на язык (замер 10 языков, суммарно ~1,6 с), `.dat` собирает
  Rust (`po2dat`), деплой — копирование;
- **накопленный мусор в установке**: `dwmapi.exp`, `dwmapi.lib`, `dwmapi_real.dll`,
  файл `nul` в корне игры; папка `<игра>/NeonTranslator/` (наш же репозиторий,
  рантайм её не использует) — установка не самоудаляемая.

## Два варианта, которые продумываем

1. **Наш установщик**: двойной клик, сам находит Steam-библиотеку (как в TSSR),
   проверяет игру, ставит «папка + лоадер», пишет манифест установки, умеет
   `--uninstall` и обновление поверх. Реализация — либо `install.cmd` + PowerShell
   (как в TSSR), либо Tauri-приложение (как `installer/` в TSSR); решение — после
   замера цены/пользы.
2. **Ручной вариант**: `.7z`/`.zip` с той же раскладкой + `README.txt`
   («распаковать туда-то»), без скриптов — на случай антивирусов/портативности
   (в TSSR так сделан основной путь для Nexus).

## Предлагаемая раскладка (вариант «одна папка»)

```text
<игра>/
  dwmapi.dll                      # единственный файл вне папки; лоадер
  NeonTranslator/                 # ВСЁ остальное — удаляется одной папкой
    NeonTranslatorRuntime.dll
    fonts/{RobotoCondensed-Regular,NotoSansSC,NotoSansJP}.ttf
    patch_ru.dat … patch_it.dat   # только выбранные языки
    active_lang.txt
    install-manifest.json         # что поставлено (для аннинсталла/обновления)
```

Требуется: одна строка в `dwmapi_proxy.c` (путь к рантайму) + рантайм разрешает
шрифты/даты/`active_lang` относительно собственного расположения (проверить в C#).
Альтернатива — BepInEx (`winhttp.dll` + `BepInEx/plugins/`): стандарт сообщества,
но тащит чужую инфраструктуру; наш прокси даёт тот же результат одним файлом.

2. Достаточно ли одной строки в прокси или нужен манифест зависимостей
   (`dwmapi_real.dll`)? Откуда берутся `.exp/.lib` в корне и как перестать их писать?
3. Авторы игры/сообщество: рекомендуют ли BepInEx/MelonLoader для TCNN; есть ли
   официальный мод-API (папка плагинов)?
4. Формат дистрибутива: `.7z` (как TSSR) или `.zip`; нужен ли FOMOD/Vortex?
5. Обновление поверх: манифест + `--uninstall` + повторная установка, или
   «удалить папку и поставить заново»?
6. Антивирус/ложные срабатывания на прокси-DLL и на `.exe` установщике — что
   подписываем/как объясняем в README.

## Приёмка

- После установки в папке игры новых файлов ровно два «места»: `<игра>/dwmapi.dll`
  и `<игра>/NeonTranslator/`; вне их — ничего.
- `--uninstall` удаляет всё поставленное и не оставляет пустых папок; повторный
  запуск игры после удаления не падает.
- `Steam → Проверить целостность` **не** перекачивает ни одного файла игры ни после
  установки, ни после удаления (доказательство «мы не меняем игру»).
- Ручной архив ставится без скриптов и даёт тот же результат.
- Игра запускается на каждом языке, `NeonTranslator.log` чистый.

## Этапы

1. Планирование раскладки и решение по установщику (сейчас, без игры).
2. Правка прокси и рантайма под «одну папку» + манифест + `--uninstall` в деплое.
3. Сборка дистрибутива (архив + установщик) и README.
4. **BLOCKED до отдельной сессии с владельцем**: чистая переустановка игры
   (`Steam → Удалить → Установить`), снимок хэшей → установка → `Проверить
целостность` → снимок хэшей → аннинсталл → проверка «ни одного лишнего файла».
   Владелец: «игру пока не удаляем, я это отдельно сделаю вместе с тобой позже».
