# [2026-11-21] Языковые пакеты правил: 8 языков без `translates/<code>.md`

Статус: READY

## Задача от пользователя

«настраивать для него скилы и тулы для переводов… большое ревью с оптимизанией
и кайдзэн делаем.»

## Цель

К переводу на любой из 10 целевых языков должна быть готова языковая
специфика: обращение/род, SFX, типографика, глоссарий. Сейчас файлы правил
есть только у `ru` (полный) и `de`/`pl` (DRAFT).

## Контекст (проверено 2026-11-21)

- `config/language-priority.json`: `en` (источник) → `zh`, `ru`, `es`, `pt`,
  `de`, `ja`, `fr`, `pl`, `ko`, `it` (11 всего).
- `.opencode/skills/translates/` содержит `core.md`, `ru.md`, `de.md`,
  `pl.md`. Для `zh`, `es`, `pt`, `ja`, `fr`, `ko`, `it` файлов нет.
- `translate_local.py` в этом случае печатает
  «NOTE: no per-language rules section yet — generic mode + shared core»
  и переводит generic-промптом; SFX и обращение не локализованы.
- Покрытие: ru 18 596/33 271 (55,9 %), de и pl по 11 155 (33,5 %), остальные
  ~0 (4 записи). То есть сейчас реально нужны ru/de/pl, но очередь языков
  определена конфигом, и «новый язык = новый файл» — правило скилла.

## Что сделать

1. Приоритет — языки с ненулевым покрытием или ближайшие в очереди.
   Минимум для этой задачи: `es`, `pt`, `fr`, `it` (латиница, проще проверять),
   затем `zh`, `ja`, `ko` (CJK: нужны правила пунктуации/переносов).
2. Для каждого языка — файл по структуре `de.md`/`pl.md`:
   - блок `<!-- PROMPT-START -->…<!-- PROMPT-END -->`;
   - обращение (ты/Вы, du/Sie, pan/pani, tu/vous…), род глаголов/прилагательных;
   - SFX-таблица (звуки как звуки, не транслитерация);
   - типографика (кавычки, тире, многоточие);
   - глоссарий имён/терминов (только дельта к `core.md`).
3. Проверить, что `translate_local.py --lang <code> --dry-run` подхватывает
   PROMPT-блок (в system-промпте появляются правила языка) — на 1 языке
   достаточно, остальные по шаблону.
4. Если файла нет — поведение остаётся generic (не падать), это зафиксировать
   тестом/примечанием в SKILL.md.

## Приёмка

- У каждого из 10 целевых языков есть `translates/<code>.md` (или явно
  записано, почему языка нет в очереди).
- `--dry-run` для 2–3 языков показывает правила языка в system-промпте.
- `translates/SKILL.md` перечисляет актуальные файлы и их статус (DRAFT/готов).
- `npm run check:langs` не ломается (файлы правил не влияют на состав po).
