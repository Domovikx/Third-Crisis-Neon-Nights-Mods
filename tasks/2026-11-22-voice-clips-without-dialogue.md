# [2026-11-22] 155 озвучек без диалога: проверить, рисуются ли по ним субтитры

Статус: READY

## Цель

Разобраться с репликами, у которых в дампе есть только имя `AudioClip`, а текста нет
ни в `dialogues[]`, ни в POT. Если игра рисует по ним субтитры — это ещё ~155 строк
видимого текста вне перевода; если нет — закрыть вопрос и зафиксировать.

## Контекст (замер 2026-11-22)

Озвучка — косвенный, но честный индикатор реплик: имя клипа обычно содержит текст.
Из 4 202 имён озвучки с «прозаическим» телом:

- 3 824 совпали с POT точно (после снятия `NN-`/`VAZoey - NNN -` и разметки);
- 141 — обрезанный префикс реплики POT;
- **237 не нашли пары**, из них после фаззи-сверки (≥75 % слов) осталось **155**,
  которых нет в POT.

Примеры (адрес — `asset:path_id`, объект `AudioClip`):

- `sharedassets14.jsonl:191` — `52-H-Hey Zoey. Uhm- hello... madam. You usually don't come back here.`
- `sharedassets17.jsonl` — `20-Oh! Leona asked about ya. She was wondering if you'd come see her…`
- `resources.jsonl` — `6-No... I'm more into girls anyway.`
- `sharedassets4.jsonl` — `24-God you're so hot, Zoey...` (этот есть в POT как реплика —
  пример «ложного непокрытия» из-за обрезки имени, поэтому часть 155 может быть такой же)
- `resources.jsonl` — `22-Open up! Let it heal your itch from within, Skank!`

Важно: в дампе этих текстов нет **вообще** (grep по всем `dialogues[]` и `raw_strings`
даёт только сам `AudioClip`). Значит либо это голос без субтитра, либо диалоговая
запись не дампится (например, лежит в объекте, который не читается).

## Что сделать

1. Проверить в живой игре 5–10 таких реплик (по одной из разных сцен): вывести на экран
   и посмотреть, есть ли субтитр. Харнесс рантайма уже умеет логировать отрисованные
   строки — использовать его, а не глаза.
2. Если субтитры есть: расширить дамп (связать `AudioClip` с диалоговой записью или
   искать текст в объектах, которые сейчас `read_failed`) — отдельная подзадача.
3. Если субтитров нет: записать в `docs/voice-naming.md`/MAP, что имена озвучки —
   не источник текста, и закрыть.

## Приёмка

- [ ] Проверено ≥5 реплик из разных сцен, результат (субтитр есть/нет) с адресами
- [ ] Решение зафиксировано: «дамп расширяем» или «не текст игрока»

- [ ] Число подтверждённо видимых строк добавлено в `docs/pot-coverage-audit.md`
