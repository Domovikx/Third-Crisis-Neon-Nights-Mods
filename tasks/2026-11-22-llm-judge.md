# [2026-11-22] LLM-судья качества перевода (помечает, не переводит)

Статус: READY

## Задача от пользователя

«пользователи от нас ожидают качественный перевод… надо подумать что и как мы делаем,
сделать план».

## Цель

Дать ревьюеру **очередь сомнительных строк** вместо сплошного чтения 40 000 записей: модель
ставит флаги по рубрике (смысл, тон, терминология, род/обращение, машинные артефакты), человек
разбирает только помеченное. Судья **ничего не переводит и не правит** — только предлагает.

## Контекст

- `npm run qa` (Rust) ловит механику: покрытие, теги, copy-through, пустые диалоги, латиницу.
  Смысловые ошибки он не видит по определению.
- `translate_local` переводит батчами через OpenAI-compatible API; пакеты языков —
  `translates/<code>.md`.
- План и место судьи в процессе — `docs/translation-plan.md` (стадия 5).
- В соседнем проекте TSSR судья-флагатель уже обкатан (рубрика v10, калибровка на дефектах).
  Берём **идею и рубрику**, код пишем свой: атомарность проектов, никаких импортов.

## Что сделать

1. Рубрика: классы дефектов (смысл искажён, потерян оттенок, сломан род/обращение, неверный
   термин, машинный артефакт, лишняя/потерянная часть) + что считается «чисто».
2. Вход судьи: строка оригинала, перевод, спикер/контекст (если есть), пакет языка.
   Выход: `{verdict: ok|flag, classes: [...], note}` — строгий JSON, без свободного текста.
3. CLI `npm run judge -- --lang ru [--limit N] [--only-flagged]`: пишет `tmp/judge-<lang>.jsonl`,
   сводку по классам; **не правит** `po/`.
4. **Калибровка**: сделать набор из 30–50 вручную размеченных строк (чистые + с дефектами),
   прогнать, замерить precision/recall. Порог приёмки судьи — не ниже 0.8 recall при ≤0.2
   ложных на чистых (цифры уточнить после первого прогона).
5. Интеграция: флаги попадают в `qa:review`/HTML как отдельная секция «сомнительные».

## Приёмка

- [ ] Судья выдаёт строгий JSON, не падает на пустых/битых строках
- [ ] Калибровочный набор размечен вручную и закоммичен (без данных игры — синтетика/свои строки)
- [ ] Замерены precision/recall на наборе; цифры записаны в задачу
- [ ] `tmp/judge-<lang>.jsonl` и сводка генерируются одной командой
- [ ] `po/*` не изменяются (проверяется тестом)
- [ ] Тесты: JSON-валидация ответа, ретраи, обрезка контекста, пустой вход

## Вне рамок

- Автоматическая правка переводов.
- Оценка стиля «нравится/не нравится» без критериев.
- Перевод (это `translate_local`).
