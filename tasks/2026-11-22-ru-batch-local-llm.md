# [2026-11-22] Батч `ru` локальной LLM (index-translate-9b)

Статус: READY (после дампера и POT→PO)

## Задача от пользователя

«потом подрубай наш локальный ллм переводчик».

## Цель

Перевести `ru` до 100 % переводимых строк **нашим** локальным переводчиком
(`index-translate-9b`, LM Studio, `127.0.0.1:1234`), с замерами и без мусора в `po/`.

## Гейт (почему не сейчас)

Запуск возможен только после:

1. **Дампер** — без молчаливых обрезок (иначе переводим неполный набор строк).
2. **POT→PO** — в PO не попадает не-текст: провенанс (`#. src:`) + пропуск `raw-bin|asset-name`.
   Без этого модель «переводит» байты: инцидент 2026-11-22 записал
   `msgstr "!+5=DHISSSSSSSSSSQOJC;1'"`.

## Замеренные параметры (2026-11-22, эта машина)

- Модель: `index-translate-9b` (5.97 ГиБ VRAM), загрузка ~10.6 с.
- **`--batch 5`**: 50 строк за 174 с → 22 переведено, 23 в триаж, **5 не разобралось** (10 %).
- **`--batch 10`**: 50 строк за 412 с → 32 переведено, 1 в триаж, **17 не разобралось** (34 %)
  → **батч 10 хуже**: медленнее и вдвое больше сбоев. Рабочий режим — **batch 5**.
- Ожидаемая скорость ~7.6 переведённых строк/мин → на ~9 800 переводимых строк `ru`
  это порядка **20 часов** (плюс сбои).

## Что сделать перед запуском

1. Починить разбор ответа: 10 % «unparsable» на batch 5. Стратегия: при сбое — повтор того же
   чанка уменьшенным батчем (5 → 3 → 1), и только потом `failed`. Счётчик сбоев в отчёт.
2. Убедиться, что мусор не уходит в модель (см. гейт).
3. Прогнать **пилот 200 строк** и посмотреть глазами 20 из них (плюс судья, когда будет).
4. Запуск полного прогона — порциями (`--limit`), resumable, с логом и без потери записанного.
5. После прогона — `npm run qa`, `po2dat`, проверка в игре (E2E `ru`).

## Приёмка

- [ ] Сбой разбора ≤2 % (было 10 %) за счёт понижения батча на ретрае
- [ ] В `po/ru.po` нет `msgstr`, которые не являются текстом (проверка линтером/POT-контрактом)
- [ ] Пилот 200 строк: 20 строк просмотрены человеком, замечания записаны
- [ ] Полный прогон завершён; число пустых = 0 по переводимым строкам (skip исключены явно)
- [ ] `npm run qa`: жёсткие правила — 0 ошибок
- [ ] `po2dat` собран, E2E `ru` в игре пройден
- [ ] Модель выгружена после прогона (`lms unload --all`), VRAM свободна
