# [2026-11-22] POT: триаж `global_strings` (57 539 строк, источник не читается)

Статус: READY

## Цель

Решить судьбу `summaries.global_strings`: сейчас это 75 795 строк в дампе (57 539
уникальных), которые **никто не читает**. Не включать вслепую (там 90 % — заметки
разработчика, FSM-параметры и обрывки), а сделать воспроизводимый триаж и забрать
только то, что похоже на отображаемый текст.

## Контекст (замер 2026-11-22)

- `global_strings` — печатные строки из не-объектных байтов ассета, до 500 на ассет.
- 57 539 уникальных; 10 282 уже есть в POT (в основном имена UI-объектов), 47 257 — нет.
- «Похоже на прозу» (3+ слова, строчные буквы, без `_ / : { } < >`): **1 120**;
  после вычета строк, которые уже есть в `raw_strings`, остаётся **891**.
- Из выборки 40: ~5 % — осколки реального текста, остальное — заметки вида
  `Did we grab the Bunnysuit already?`, `This whole section was cut from the game`,
  `Play later dialogue`, `Set blocker task`. Плюс много обрезков на не-ASCII
  (`to craft my true self.l`, `nup Video Booster`).
- Найденные «текстовые» кандидаты: `Come here, bitch.` (единственная реплика),
  `Has Vampire Outfit?`, `Give Sucky Wig`, `Is on Mission to find Bunnysuit`
  (похоже на отладочные/квестовые флаги).
- Причина, почему сейчас пусто: `inventory.mts` читает только `settings_keys` из
  summaries, `global_strings` игнорирует.

## Что сделать

1. Написать диагностический проход (tmp) с фильтром «это отображаемый текст»:
   - ≥3 слов, есть строчная буква;
   - нет `_`, `/`, `\`, `:`, `=`, `{`, `}`, `<>`;
   - нет известных отладочных префиксов (`Play `, `Did `, `Set `, `Setup `, `Setup `,
     `Reset `, `Wait `, `Start `, `Turn on/off `, `Deactivate `, `Activate `);
   - не обрывок (начинается с пробела/знака или оканчивается на середине слова).
2. Прогнать фильтр, руками просмотреть результат (ожидаемо ≤ 100 строк) и решить:
   - включать ли `global_strings` как `kind`, и с каким контекстом;
   - или ограничиться списком вручную отобранных строк (YAGNI, если их меньше 50).
3. Не создавать дублей: строка, уже покрытая `dialogues`/`raw`, не добавляется.
