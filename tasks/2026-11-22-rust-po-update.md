# [2026-11-22] POT→PO на Rust: `po_update` (+ prefill, find_source) поверх общего ядра

Статус: READY

## Задача от пользователя

«помним про миграцию на РАСТ» — TS остаётся для UI, оркестрации и эталонов; вычисления
с плотными данными уходят на Rust по замеру.

## Цель

Перенести `po_update` (перенос переводов в новый POT) на Rust поверх `tools/rust-l10n-core`,
затем `prefill_po` и `find_source`. Парсер PO остаётся **один** (сейчас у `po_update` свой TS,
у `qa`/`potgen` — Rust).

## Контекст (замеры 2026-11-22)

- `po_update` (TS): **381 мс** на язык (3.1 МБ `ru.po` + 2.2 МБ `template.pot`), на 10 языках ~3.8 с.
- `po2dat` после порта: **4.4×** (81 против 17 МБ/с) — ожидаемый порядок и здесь.
- Профит по правилу: прирост ≥10 % заведомо достигается, плюс **DRY**: `rust-l10n-core` уже
  содержит `po` (парсер + рендер) и `dat`.
- `po_update` — ровно тот инструмент, из-за которого появились 1 321 мёртвый перевод:
  он не печатал выпавшие ключи. Порт делаем **вместе с этим дефектом** (см. п. 2).

## Что сделать

1. Подкоманда `rust-l10n po_update [lang] [--po-dir]` на общем ядре; паритет: `po/<lang>.po`
   байт-в-байт с TS-версией на всех 10 языках (кроме дат).
2. **Починить учёт выпавших ключей**: печатать и считать `dropped` (ключи, которых больше нет
   в POT), `retargeted`, `carried`, `new`, `orphans`; при выпадении — явное предупреждение.
   Это закрывает класс «перевод есть, применить некуда».
3. Не терять варианты при удалении дублирующихся контекстов (те 48 групп): если у ключа было
   несколько переводов, решение фиксируется (первый по правилу) и **сообщается**.
4. Затем `prefill_po` и `find_source` — на том же ядре, с паритетом.
5. Обёртки: `npm run po:update` → Rust; `po:update:ts` — эталон. Без бинаря — понятная ошибка.
6. Замер «до/после» на 1× и 10× (синтетика в `tmp/`).

## Приёмка

- [ ] Печатает `dropped`/`retargeted`/`carried`/`new`/`orphans`; выпавшие — с предупреждением
- [ ] Варианты дублей не теряются молча (решение + сообщение)
- [ ] `cargo clippy -D warnings`, `cargo fmt --check`, `cargo test` — чистые
