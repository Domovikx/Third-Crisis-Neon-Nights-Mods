# [2026-11-23] Чистка «перевод = оригинал» в PO (404 строки)

Статус: READY

## Зачем

Ревью `ru` 2026-11-23 показало **404 живые строки, где `msgstr` буквально равен `msgid`**:
378 из них — короткий мусор (имена ассетов `Bark 2`, `Check 2nd Save Key`, состояния
`ACCESS`, `ALT`, `ARRIVAL`, `Action PMA_IsNude`). Такие строки попадают в `.dat`, но перевода
не дают: игрок видит английский текст, если он вообще показывается.

## Что сделать

1. Разложить 404 по классам: ассет/состояние/подпись/настоящий текст.
2. То, что не текст — в `config/pot-skip-ids.json` (подтверждённый список) или новым
   структурным правилом, если класс однородный.
3. То, что настоящая подпись (например, `ACCESS`, `ARRIVAL`) — перевести, а не скипать.
4. Повторить для остальных языков, когда дойдёт очередь (`de`/`pl` унаследованы).

## Приёмка

- количество `msgstr == msgid` среди живых = 0, либо каждая оставшаяся строка объяснена
  (осознанно одинаковый перевод вроде `OK`);
- `npm run rt:audit --strict` и `npm run verify` зелёные;
- отчёт: сколько классов, что ушло в skip, что переведено.

## Вне рамок

- Переписывание легаси-переводов `de`/`pl` целиком (отдельная задача после `ru`).

## Прогресс (2026-11-23, вечер)

Сделано попутно с ревью качества:

- правило `snake-case` сняло 314 записей (`CC_Option_*`, `Apl_*`, `PMA_*`);
- правило `fsm-label` сняло 12 (`FSM Lio Printer`, `FSM Nova Moving In`);
- скриптовые метки с id-суффиксом — 5 записей в подтверждённый skip-список;
- осталось **360** живых строк `msgstr == msgid`: 171 `raw:MonoBehaviour` (ACCESS, ARRIVAL —
  часть реально видна игроку), 146 без провенанса (мусорные строки дампа), 25 `us`
  (отладочные сообщения Unity), 6 `dialog` (мусор: `...`, `>`, типы .NET).
- Реальных реплик без перевода не осталось: все 6 `dialog` — не текст.
