## Цель

Проверка качества перевода и пакетный перевод локальной LLM работают на TS: можно прогонять
QA и доливку языков без Python-окружения.

## Контекст

- `qa_translate.py` (234) — офлайн-QA: покрытие, баланс тегов, латиница в переводе, повторы;
  отчёт в `tmp/qa.html`.
- `review_queue.py` (192) — очередь ревью в HTML (тот же семейный стиль).
- `translate_local.py` (487) — пакетный перевод пустых `msgstr` через OpenAI-compatible API
  (LM Studio и аналоги): пауза/резюм, запись по записи, валидация тегов.
- Все три опираются на `po_file.py` (уже портирован).
- **Длина перевода НЕ критерий качества** — проверки «msgstr длиннее/короче msgid» запрещены.
