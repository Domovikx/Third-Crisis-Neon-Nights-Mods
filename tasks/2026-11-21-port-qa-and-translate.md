# [2026-11-21] Портировать QA и пакетный перевод: `qa_translate`, `review_queue`, `translate_local`

Статус: READY

## Задача от пользователя

Часть общей задачи: «максимально запускаем миграцию на ts mts вместо питона».

## Цель

Проверка качества перевода и пакетный перевод локальной LLM работают на TS: можно прогонять
QA и доливку языков без Python-окружения.

## Контекст

- `qa_translate.py` (234) — офлайн-QA: покрытие, баланс тегов, латиница в переводе, повторы;
  отчёт в `tmp/qa.html`.
- `review_queue.py` (192) — очередь ревью в HTML (тот же семейный стиль).
- `translate_local.py` (487) — пакетный перевод пустых `msgstr` через OpenAI-compatible API
  (LM Studio и аналоги): пауза/резюм, запись по записи, валидация тегов.
- Все три опираются на `po_file.py` (уже портирован).
- **Длина перевода НЕ критерий качества** — проверки «msgstr длиннее/короче msgid» запрещены.

## Что сделать

1. Прочитать три модуля и их тесты.
2. Вопросы ресёрча:
   - как в TS организовать HTTP-клиент без зависимостей (встроенный `fetch` достаточно?);
   - как воспроизвести пофайловую запись «по записи» с возможностью остановки и продолжения;
   - какие проверки QA дают ложные срабатывания на русском (например, латиница в именах
     собственных) — зафиксировать как известные и не «чинить» при порте.
3. Реализовать на `.mts` с тестами; сетевые вызовы в тестах — на локальном фейковом сервере
   (`node:http`), без реальной LLM.
4. Паритет: `qa_translate` на реальных `po/ru.po` и `po/de.po` — отчёт совпадает по числам
   (покрытие, количество флагов) с Python.
5. Удалить `.py` из нового дерева, обновить `SKILL.md` скиллов.

## Приёмка

- [ ] `qa_translate.mts` на `po/ru.po` и `po/de.po` даёт те же числа, что Python (покрытие,
      число флагов по категориям)
- [ ] `review_queue.mts` генерирует HTML в `tmp/`, файл открывается
- [ ] `translate_local.mts` на фейковом OpenAI-сервере: переводит, останавливается по флагу,
      продолжает с места останова, не теряет уже записанное
- [ ] Тесты не требуют сети и не зовут реальную LLM
- [ ] `npm run typecheck`, `npm run lint`, `npm test` зелёные
- [ ] `.py` удалены, `docs/migration.md` обновлён
