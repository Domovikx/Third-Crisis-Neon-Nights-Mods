# [2026-11-22] RAG-контекст для переводчика: лёгкий вариант с замером

Статус: READY (делать после аудита данных)

## Задача от пользователя

«тут я не совсем понимаю о чем это, но если это даст профит проекту, то давай сделаем».

## Что это по-человечески

Переводчику (и модели) перед каждой строкой подмешивается **релевантный контекст**:

- как этот же термин/имя переводили раньше в этом языке (глоссарий + фактические переводы);
- как звучали соседние реплики этого же спикера;
- похожие по смыслу строки и их принятые переводы.

Идея взята из класса «память + поиск по корпусу» (MemoRAG и родственные), но **без** второй
модели и эмбеддингов: сначала дешёвый поиск по ключевым словам (BM25/токены).

## Зачем (гипотеза, которую надо проверить)

Главные дефекты качества на длинном корпусе — **несогласованность**: один термин переведён
тремя способами, имя склоняется по-разному, обращение плавает. Контекст должен это уменьшить.

## Гейт (по правилу «профит в процентах»)

Эксперимент обязан показать **≥10 %** улучшения по измеримой метрике, иначе не берём:

- метрика: доля ошибок класса «терминология/род/обращение» по судье
  (`tasks/2026-11-22-llm-judge.md`) на одинаковой выборке;
- базовая линия — прогон без контекста, затем с контекстом, те же строки, та же модель.

## Порядок

Сначала `tasks/2026-11-22-data-integrity-lint.md`: подмешивать контекст из данных, в которых
могут быть структурные баги, бессмысленно — сначала доверие к данным.

## Что сделать

1. Индекс по `po/<lang>.po`: принятые пары (оригинал → перевод), глоссарий из `translates/<code>.md`.
2. Поиск кандидатов: BM25 по токенам оригинала + точные совпадения терминов; без эмбеддингов.
3. Встраивание в `translate_local`: блок «похожие строки и как их переводили» + глоссарий,
   с жёстким лимитом токенов (не раздувать промпт).
4. Замер на `ru`: 200 строк, две конфигурации, судья, сравнение по классам.

## Приёмка

- [ ] Индекс строится из `po/<lang>.po` за секунды, без внешних сервисов
- [ ] Промпт с контекстом не превышает лимит токенов (тест)
- [ ] Замер «без контекста / с контекстом» на 200 строк, по классам дефектов
- [ ] Прирост ≥10 % по целевой метрике — берём; меньше — задача закрывается с числами
- [ ] `npm test`, `npm run test:qa` зелёные

## Вне рамок

- Изменение правил перевода в `translates/`.
