# Карта персонажей TCNN (для озвучки)

Данные: `po/template.pot` (7 324 диалоговые строки без `skip`; к озвучке 7 282 —
минус 42 стона M0/M1), клипы игры из `tmp/dump`, снимок 2026-11-25.
Машиночитаемая версия — `config/voice-characters.json`; пересобирается
`node tmp/gen_voice_characters.mts`.

Термины:

- **Строк** — строки, где в POT явно стоит `speaker:<Имя>`;
- **К озвучке** — без чистых стонов M0/M1 (стоны и ASMR в игре уже есть);
- **Озвучено** — строки, покрытые оригинальными клипами (найдено по тексту, см.
  `tasks/2026-11-25-voice-research-report.md`);
- **Реф** — варианты в `voice-demo/refs-ready/` (A/B/C — длина, X — пробный).
