# Карта персонажей TCNN (для озвучки)

**Источник истины — `config/voice-characters.mts`** (типизированный модуль,
порядок ключей = приоритет). Таблица и описания ниже — читаемая проекция модуля;
при расхождении верен модуль. Страж — `config/voice-characters.test.mts`
(покрытие спикеров POT в обе стороны, пол, приоритеты, пути рефов).

Данные: `po/template.pot` (7 324 диалоговые строки без `skip`), клипы игры из
`tmp/dump`, снимок 2026-11-25. Пол — из `config/speaker-gender.mts` (грамматика
1-го лица; `null` = данных мало, не угадываем). Рефы — `voice-refs/<Персонаж>/`
(`candidates/` — заготовки, `chosen/` — выбранный вручную).

Термины:

- **Строк** — строки, где в POT явно стоит `speaker:<Имя>`;
- **К озвучке** — без чистых стонов M0/M1 (стоны и ASMR в игре уже есть);
- **Озвучено** — `yes` (сцены целиком), `partial` (часть реплик / даб), `no`;
- **Реф** — варианты в `voice-refs/<Персонаж>/candidates/`; `chosen` пока пуст.

## Оговорки

- Числа по Зои: 1 231 — точная (явный `speaker:Zoey`), 2 225 — оценка сверху
  (мысли в скобках без спикера; часть из 4 793 неатрибутированных строк
  принадлежит не ей).
- У Nova 0 явных строк — это не «её нет в игре», а «её реплики не помечены
  спикером»; 61-с даб подтверждает, что актёрская запись существует.
- Пол Max/Rosie/Nova по грамматике не выводится; голос в оригинале слышен
  (Max — женский тембр, Rosie — женский по тейкам, Nova — женский по дабу).
- Все рефы ещё не проверены ухом (`manualCheck: "pending"`); из текущих заготовок
  как отправная годится только Zoey. Заготовки — не приговор, владелец может
  заменить любую.
