# UI-кит игры и наши элементы (метрики, а не «на глаз»)

Снято 2026-11-25 с живой сцены главного меню (`tmp/shots/menu-*.png`, TMP/Image из
иерархии — см. `NeonUiProbe` в логе рантайма) плюс пиксельные замеры скриншота 1:1.
Цель — привести нашу панель языка и подписи кнопок к ритму игры, а не к «веб-плоскости».

## Что снято с игры (главное меню)

Источник: TMP-компоненты кнопок `ButtonContainer/*/Background/Text (TMP)`, Image
`.../Background`, `VerticalLayoutGroup`, материал TMP, CanvasScaler.

| Метрика | Значение в игре |
| --- | --- |
| Плитка кнопки (Image «Background») | **420 × 72** (ref px), спрайт `GenericSquareTiltedButton`, `Sliced`, border 24/0/24/0 |
| Корень кнопки (ANButton) | 92 × 72 (это «хват», плитка шире) |
| Скругление | **0** (border по вертикали 0; на скриншоте радиус ≈2 px — это антиалиас, не радиус) |
| Обводка плитки | 1–2 px **чёрная**, запечена в спрайт |
| Тень | чёрная, узкая (≈3–5 px по краю при scale 0.75); цветной тени нет |
| Расстояние между кнопками | **9** (`VerticalLayoutGroup.spacing = 9`, padding 0, forceExpandHeight) |
| Кегль подписи | **36** TMP, `FontStyles.Normal` |
| Начертание/лицо | `Orbitron-Black SDF` (point 90, `m_Scale` 1, padding 9, SDFAA) |
| `characterSpacing` / `wordSpacing` / `lineSpacing` | **0 / 0 / 0** |
| Выравнивание, margin | Center; margin (0.69, 0, 0, 1.2) |
| Текст: цвет | **#000000** на белой плите |
| Текст: тень | TMP underlay **#000000 @ 0.50**, offset (0,0), softness 0 |
| Материал | `Orbitron-Black Atlas Material`, shader `TextMeshPro/Distance Field`, `_OutlineWidth 0`, `_GradientScale 10` |
| Hover/press | `Selectable.transition = Animation` (ANButton-твин), ColorBlock #979797 → #F5F5F5 (hi) → #C8C8C8 (press), fade 0.1 |
| Внутренние отступы подписи | текст 387.74 × 58.79 в плите 420 × 72 → ≈16 px L/R, ≈6.6 px T/B |
| CanvasScaler игры | 1920 × 1080, **match 0** (по ширине), scaleFactor 0.75 при 1440 |
| Панель/попап | в сцене меню только `verticalfade_QuadInOut` (#FAE360, Sliced, border 0/2034/0/0) — вертикальный градиент, не карточка; готового «панельного» спрайта нет |

Пиксельная проверка (скриншот 1600×900, canvas scale 0.75): плитка ≈331 × 54 px,
угол квадратный (профиль 2,1,1,1,0 px), слева 1 px почти чёрный контур и полоса
темнее фона ≈20 % — это и есть «чёрная тень», а не синяя/цветная.

## Наши элементы — что берём и почему

| Элемент | Решение | Почему |
| --- | --- | --- |
| Панель языка | bg `#10141F` @0.93, радиус **2**, обводка **1.5 px чёрная** @0.9, тень **чёрная** @0.55 (смещение 0/−6), поля 24 | У игры нет цветных свечений; единственная «тень» — чёрная. Радиус 2 = фактический 0 + сглаживание |
| Строки языков | Белая плита `#FFFFFF`, текст **чёрный**, высота **48**, шаг **56** (48+8), padding 16 | Ритм игры: белая плита + чёрный текст, шаг кратен 8. 48 = 72 × 2/3, кегль 24 = 36 × 2/3 |
| Выбранный язык | Розовая полоса 3 px + текст `#C71059`, плита чуть розовее | Акцент игры — неон-розовый; но только маркер выбора, не фон и не тень |
| Мини-кнопка | Белая плита 104 × 40, радиус 2, **чёрная** обводка, чёрный текст 20 bold, розовая точка | Та же плитка, что у кнопок игры; точка — индикатор языка |
| Заголовок панели | «LANGUAGE», Roboto Condensed 22 bold, белый | Orbitron без кириллицы, а заголовок не должен «прыгать» между языками |
| Подписи главного меню | кегль 36 → **38** (×1.068), `characterSpacing` **−8**, авто-подгонка с полом 60 % | Высота строки игры 46.35 px; наша кириллица при 36 px даёт 43.39 px → ×1.068 восстанавливает высоту, −8 возвращает ширину |
| Кириллица в меню | клон игрового `Roboto-Condensed_DialogueUI` (TTF игры, point 95, padding 9, материал игры) первым в fallback-цепочке | Orbitron-Black **не содержит кириллицы** (glyph index 0), поэтому «родной» рисунок меню для ru невозможен; берём ближайший игровой шрифт с его же материалом |

Чего **не** берём: наклонный спрайт-параллелограмм (это чужая графика, повторять её
пиксельно нельзя без ассета), зелёное свечение материала (`_GlowPower` в игре
включён, но визуально не читается — на белой плите даёт грязь), анимационный
твин ANButton (наш UGUI-слой живёт вне их системы — используем цветовой hover).

## Главное меню: EN-эталон vs RU (финальные метрики)

Эталон — **оригинальный английский UI** (`--lang en`, native-режим, скриншот
`tmp/shots/menu-en-baseline.png`), снятый с TMP-компонентов до нашей замены.
Лог рантайма печатает обе стороны: `size en=36 ru=38 (x1.00) fit=ok enW=.. ruW=.. d=..%`.

| Метрика / строка | EN (игра) | RU (итог) | Δ |
| --- | --- | --- | --- |
| Кегль подписи | 36 | **38** (×1.068 — компенсация высоты) | +5.6 % |
| Высота строки | 46.35 | **45.74** | −1.3 % |
| «Продолжить» / Continue | 179.73 | **172** | −4.3 % |
| «Выход» / Exit | 77.67 | 93 | +20 % (5 знаков vs 4; в плитку 420 влезает) |
| «НАСТРОЙКИ» / Options | 153.55 | 172 | +12 % (9 знаков vs 7) |
| «Новая игра» / New Game | 220.04 | 152 | −31 % (короче, не растягиваем) |
| «Загрузить файл сохранения» / Load Save File | 305.29 | 379 → fit до **32** | влезает в плитку (игра сама ужимает эту строку до 30) |
| `characterSpacing` | 0 | **−8** | ширина «Продолжить» 188.8 → 172 |
| Лицо кириллицы | Orbitron (нет кириллицы) | клон `DXclone-Roboto-Condensed_DialogueUI` (TTF игры, point 95, padding 9, материал игры) | рисунок игры |
| Глифов у лица | 236 | 241 (клон) / цепочка 319 | 236 → 319 |

Правило подгонки: **плитка — предел**, EN-ширина — ориентир. Короткие русские
слова физически шире коротких английских; тянуть их к EN-ширине нельзя (кегль
упал бы до 29 и ритм сломался бы). Поэтому: кегль = EN × 1.068, при переполнении
плитки — уменьшение (лог `fit=shrunk`), пол 60 %.

## CJK-масштаб: проверка на тех же кнопках

`size en=36 <lang>=N (x<scale>) fit=ok|shrunk` — из лога рантайма.

| Язык | EN кегль | Итог | scale | fit | Пример ширины |
| --- | --- | --- | --- | --- | --- |
| zh | 36 | **39** | ×1.08 | ok (все 4) | «退出» 76 vs EN «Exit» 75 (+1 %) |
| ja | 36 | **39** | ×1.07 | ok / 1 × shrunk (ロード/セーブファイル, не ниже 36) | «ニューゲーム» 111 vs «New Game» 216 |
| ko | 36 | **37** | ×1.04 | ok (все 4) | «새 게임» 111 vs «New Game» 216 |
| ru | 36 | **38** | ×1.00 (menu 1.068) | ok / 1 × shrunk | «Продолжить» 172 vs «Continue» 180 |

Масштаб применяется **один раз** (в `NeonFit`), до авто-подгонки; авто-подгонка
для CJK не опускает кегль ниже EN-размера. Line-height zh = 1.6, ja/ko = 1.5 —
`typography: zh scale=1.08 lineHeight=1.60`, на многострочном тексте страницы
образцов (`specimen-zh.png`) строки не слипаются (lineSpacing 60).

Остальные экраны (диалоги, настройки, инвентарь) **не трогали** — отдельный шаг.

## Как проверить

- `tmp/shots/menu-ru.png`, `menu-zh.png`, `menu-ko.png` — меню + панель на 1600×900;
  `menu-ru-1920x1080.png` — проверка, что панель не наезжает на кнопки на 1920×1080.
- `tmp/shots/specimen-{ru,zh,ja,ko}.png` — скрытая страница (Ctrl+F12):
  все наборы символов, счётчики `glyphs=ok/total tofu=N`, красным — дыры.
- `tmp/shots/font-demo-{ru,zh}.png` — кандидаты шрифтов (F10/вкладка Compare).
- Лог: `typography: ru scale=1.00 size=36->38`, `Font: preload chain ru = True ... 236 + 83 -> 319`,
  `Fonts: assign font='DXclone-...' source='Roboto-Condensed_DialogueUI' ...`.
