# Миграция NeonTranslator → Third-Crisis-Neon-Nights-Mods

Дата старта: 2026-11-21. Статус: **в процессе**.

## Зачем

Старый репозиторий жил **внутри папки игры** (`<Steam>/…/Third Crisis Neon Nights/NeonTranslator/`):
Steam-обновление, переустановка игры или перенос библиотеки ломали рабочее дерево; CI и бэкапы
усложнены; доступ к `Program Files` требует прав. Плюс весь пайплайн был на Python, хотя по духу
проекта это образец TypeScript-решений.

Отсюда два независимых, но одновременных решения:

- **переезд** в отдельный каталог `C:\Users\Domo\workspace\Third-Crisis-Neon-Nights-Mods`;
- **миграция языка** Python → TypeScript (`.mts`), python остаётся только физически необходимым.

Старый репозиторий помечен DEPRECATED и остаётся read-only источником истории и референсов.

## Правила миграции

1. **Новый код — только `.mts`.** Python не растёт.
2. Порт = перенос **поведения**, а не переписывание «как лучше». Сначала паритет, потом улучшения.
3. У каждого порта — тесты (`node --test`) и **проверка паритета на реальных данных**:
   старый Python и новый TS получают один и тот же вход, результаты сравниваются байт-в-байт
   (с нормализацией `CRLF`→`LF`, потому что Python на Windows пишет `\r\n`).
4. Портированный модуль удаляется из старого дерева **только** после зелёного паритета.
5. Данные (`po/`, `fonts/`) переносятся как есть, без правок.

## Риски

- **Скрытая логика в `extractor.py`.** 1144 строки эвристик уже один раз дали мусор
  (all-caps строки, непредсказуемые display-имена). Порт инвентаря должен быть покрыт тестами
  на реальном дампе, иначе POT поедет.
- **Rich-разметка.** `rich_text` из дампа → POT → `.dat` → рантайм. Ошибка здесь ломает цвета и
  `<font>`-выбор, но **не** ломает текст. Проверять паритетом `.dat`.
- **Порядок строк.** POT — источник правды для порядка; `po2dat` разрешает дубликаты по
  earliest-ref-file-wins. Любое изменение сортировки = шум в диффах переводов.
- **CRLF.** Python на Windows пишет `\r\n`; TS — `\n`. Для `.dat` это безопасно
  (`File.ReadLines`), но при сравнении артефактов нормализуем.
- **Пути к игре.** Репо больше не внутри игры: любой скрипт обязан брать путь из
  `scripts/game_dir.mts` (env `TCNN_GAME_DIR` → Steam-библиотеки), без хардкода.
