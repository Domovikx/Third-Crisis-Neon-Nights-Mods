# MAP — pipeline-common (факты и грабли)

Проверено на реальном дампе Third Crisis: Neon Nights (319 МБ, 477 872 строки
JSONL, 2026-11-21). Каждая строка — «симптом → причина → проверено → что делать».

## Готчи

- ⚠️ **В POT не попадают обычные предложения из `raw_strings`** → `isUiString`
  отбрасывает ЛЮБУЮ строку с точкой, если среди первых 5 code points есть
  заглавная (эвристика «C#-поле Namespace.Field»): `isUiString("Yeah. Looks
like it.") === false` → проверено 2026-11-21 тестом
  `inventory.test.mts` («предложение с точкой отбрасывается») и замером:
  459 уникальных предложений не в POT → не менять фильтр «на глаз»: правка
  поведения = отдельная задача `tasks/2026-11-21-pot-coverage-gaps.md`.

- ⚠️ **Описания предметов и квестов теряются** → верхняя граница UI-лейбла
  50 code points (`isUiString`, строка ~228) → проверено: 50 символов
  проходит, 51 — нет (тест «границы длины»), 348 длинных предложений в POT
  отсутствуют → то же: задача `pot-coverage-gaps`.

- ⚠️ **`\` в строке = мусор** → `isGarbageFragment` считает любой обратный слэш
  признаком raw-байтов → проверено: `isGarbageFragment("C:\\Games") === true`
  (тест добавлен) → безопасно только потому, что фильтр применяется к
  raw/settings, не к диалогам; не расширять его на `dialogues`.

- ⚠️ **`pyStrip` ≠ `String.prototype.trim`** → Python `str.strip()` считает
  пробелами `\x1c-\x1f` и `\x85` (NEL), а BOM (`\uFEFF`) — НЕ пробел;
  JS-trim режет BOM и не режет NEL → проверено тестом «pyStrip: пробелы
  Python (NEL, \x1c), BOM не трогает» → в пайплайне всегда `pyStrip`, не
  `trim()`.

- ⚠️ **Сортировка строк по code points, а не UTF-16** → `compareCodePoints`
  нужен, потому что JS `sort()` сравнивает UTF-16 units: астральные символы
  (эмодзи) встают не туда, где их поставил Python → проверено: паритет POT
  байт-в-байт (2026-11-21) без `compareCodePoints` не гарантирован → не
  заменять на `a.localeCompare(b)` / `a < b`.

- ⚠️ **Два дома фильтров** → `text_filters.mts` владеет ассетами/мусором/скип-
  префиксами, но UI-эвристика `isUiString` живёт в `inventory.mts` → это
  осознанно (UI-фильтр нужен только инвентарю), но при переносе правила
  проверять оба файла; не копировать `isAssetName` в `inventory`.

- ⚠️ **Python-остров удалён 2026-11-22** → `text_filters.py` больше нет; единственный канон —
  `.mts`. Если в текстах задач/истории встретится `dump_assets.py` — это архив, не запускать.
