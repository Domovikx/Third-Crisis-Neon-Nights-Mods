# MAP — translate-local (факты и грабли)

Инструмент портирован на TS 2026-11-21 (`scripts/translate_local.mts`).
Проверено на текущем `po/` (ru 18 596 заполненных из 33 271, 14 675 пустых;
de/pl по 11 155). `.py` рядом — референс до удаления.

## Готчи

- ⚠️ **Валидация резала длинные переводы** → в `.py` когда-то был
  `len(tr) > len(src) * 2.5 + 20` («too long»), что противоречит правилу
  репозитория «длина не критерий» (`AGENTS.md`) → в порте проверки длины НЕТ,
  тест `validate: длина не критерий` зелёный → не возвращать лимиты длины ни в
  валидации, ни в QA.

- ⚠️ **JS `\W` — это ASCII, Python `\W` — Unicode** → `triage()` в Python
  считал кириллицу «словом», в JS `\W` резал бы её как мусор → порт использует
  явные классы `[^\p{L}\p{N}_]` с флагом `u` → проверено набором триаж-кейсов
  из Python-теста (`? 8fA`, `-#YA`, `- later...`, `Привет`).

- ⚠️ **`/i` для кириллицы требует флага `u`** → `BANNED_RX` (`фх|нгх|мгх|гх`)
  без `u` может не свернуть регистр в некоторых движках/сборках → стоит
  `/iu` → проверено тестом `Фхааа` → `banned cluster`.

- ⚠️ **`--model trans14` — не имя модели, а идентификатор загрузки LM Studio** →
  `lms load … --identifier trans14`; при другом идентификаторе сервер ответит
  «model not found» → проверено прошлыми прогонами (RUNBOOK в SKILL.md) →
  перед батчем сверять `curl 127.0.0.1:1234/v1/models` и передавать `--model`.

- ⚠️ **Запись po должна быть атомарной** → `.py` когда-то делал
  `path.write_text`, обрыв мог обнулить файл → в порте `applyMsgstrInPlace`
  пишет `.part` → `renameSync`, тест «inplace atomic, no .part» → не заменять
  на прямой `writeFileSync`.

- ⚠️ **Пауза — файл, а не сигнал** → `tmp/translate-local/PAUSE`, проверяется
  перед каждой пачкой → проверено тестом: после второй пачки появляется
  PAUSE, прогон встаёт (`paused: true`), повторный прогон добирает остаток и не
  трогает записанное → при зависшем процессе сначала пауза, потом разбор лога.

- ⚠️ **Название языка теперь из конфига, а не из своей карты** → в `.py` был
  `LANG_NAMES` с `zh: "Simplified Chinese"`; в TS `targetLanguage()` берёт
  `language` из `config/language-priority.json` (`zh: "Chinese"`) → для zh
  промпт стал короче на слово; уточнения — в `translates/zh.md`, не в коде.

- ⚠️ **Правила языка только для ru/de/pl** → `translates/<code>.md` есть у трёх
  языков; для остальных 8 печатается «generic mode» → проверено: скрипт
  предупреждает, но переводит generic-промптом → не ждать от ja/zh/ko качества
  без файла языка; задача `tasks/2026-11-21-translates-language-packs.md`.

- ⚠️ **`--include` фильтрует по тексту/контексту, не по ассету** → в POT нет
  `#:` refs, поэтому фильтра по сцене нет (нужен `find_source`) → проверено
  чтением кода (`--include` матчит msgid/msgctxt/refs) → не пытаться отобрать
  «только level3» этой опцией.

- ⚠️ **`{n}` в промпте подставляется, но только он** → Python делал
  `system.format(n=...)`, что падало бы на любых других фигурных скобках из
  `core.md` → в TS `formatPromptN` меняет ровно `{n}` → можно спокойно писать
  фигурные скобки в правилах языка.

- ⚠️ **Тесты не должны ходить в сеть** → полный прогон проверяется локальным
  фейковым OpenAI-сервером (`node:http`, порт 0) → реальная LLM не зовётся;
  фейк умеет отдавать HTTP-500 для проверки обрыва (`aborted: true`).

- ❌ **LM Studio GUI-сервер умирает на длинных прогонах** → `HTTP 400 {"error":"terminated"}`,
  модель выгружается, прогон встаёт (3 раза за сессию 2026-11-23). Причина: инференс живёт внутри
  GUI-приложения. Проверено: headless `llama-server` из бэкендов LM Studio
  (`-m …Q4_K_S.gguf -c 8192 -np 1 -ngl 99 --port 8081 --alias index-translate-9b`) поднимается
  за секунды и держит нагрузку (14 запросов, 0 сбоев). Что делать: долгие прогоны — только на
  llama-server, в коде `--url http://127.0.0.1:8081`.

- ⚠️ **`reasoning_effort:"none"` гасит thinking только в LM Studio.** llama.cpp это поле
  игнорирует и модель снова «думает» (пустой `content`, токены в `reasoning_content`).
  Проверено: 2026-11-23 по логам. Что делать: отправлять ОБА —
  `reasoning_effort:"none"` и `chat_template_kwargs:{"enable_thinking":false}`.

- ⚠️ **Протокол `N. перевод` протекает в текст.** Модель иногда оставляет `2. ` в самом
  переводе: в `ru` нашлось 30 таких строк, в игре видно «2. Но как ты...?». Проверено:
  2026-11-23, `po/ru.po`. Что делать: `validate` возвращает `numbering` (детектор в
  `keepsNumbering`), повтор с подсказкой; старые строки чистить, если оригинал не начинается с
  числа.

- ⚠️ **Просить модель «расставить теги» бесполезно — она пересказывает.** 32 строки `ru` так и
  остались без `rich_translation` (проверено 2026-11-23). Что делать: span-режим
  (`npm run rt:pass -- --mode span`) — модель выбирает фрагмент перевода, теги вставляет код,
  текст без тегов гарантированно равен `msgstr`.

- ⚠️ **Смена промпта не переписывает старые переводы.** Добавили контекст сцены — 139 уже
  переведённых строк остались «без контекста». Проверено 2026-11-23 (`tmp/pre-context-msgids.txt`).
  Что делать: после изменения промпта сохранить список «переведено до» и обнулить его для
  повторного прогона; иначе качество партии будет разным без отметки.

- ❌ **LLM-судья не умеет судить регистр 18+.** Первый прогон (index-translate-9b, 120 строк)
  дал 34 флага `register-soft` и 4 `register-clinical`, из которых верных — единицы: стоны
  («Не может-.. Быть так-.. Хорошо-..») записаны в клинику, нормальная наррация — в «смягчение».
  Проверено 2026-11-23. Что делать: регистр мерить лексиконом (`scripts/register_lexicon.mts`:
  клинические корни + потеря откровенных слов), судью спрашивать ТОЛЬКО про грубые ошибки.

- ⚠️ **Первая ступень судьи — находка, не приговор: точность ~30 %.** На выборке 300 строк
  «грубых» оказалось 8, из них реальных 3; остальные — парафраз, эротическая идиома, кривой
  источник. Проверено 2026-11-23. Что делать: вторая ступень verify (одно обвинение + few-shot
  примеров отказа) — 7/8 на отложенной выборке; править только её подтверждённые строки
  (`qa_judge` → `.bad.jsonl` → `translate_local --improve --keys`).

- ⚠️ **Модель возвращает собственный промпт вместо перевода.** В ru нашлось 4 строки с текстом
  «Перевод каждой строки. Отвечайте ровно одной строкой…» (2026-11-23). Судья-LLM это НЕ ловит:
  на обвинение «instructions, not source content» отвечает «dismissed». Что делать: механика —
  `scripts/leak_guard.mts` + проверка `prompt leak` в `validate`.

- ⚠️ **Improve-режим: модель копирует метку `RU:` и теряет кавычки.** Из 10 строк 6 получили
  «RU: …» в начале, одна — без открывающей кавычки («Я искренне…» вместо «"Я искренне…»).
  Проверено 2026-11-23. Что делать: `stripEchoLabel` (эхо метки) и `keepsFraming` (рамка
  кавычек/скобок) в `validate`; обе — с тестами. Остаток: 103 легаси-строки без скобок,
  где EN — внутренняя мысль в скобках.

- ⚠️ **`translate_local` по умолчанию идёт на 1234 (LM Studio).** Долгие прогоны у нас на
  headless 8081, и без `--url` прогон падает «fetch failed» (теперь с причиной в скобках:
  `connect ECONNREFUSED 127.0.0.1:1234`). Проверено 2026-11-23. Что делать: всегда
  `--url http://127.0.0.1:8081` при headless-сервере.

- ⚠️ **`stripEchoLabel` нужно применять в ОБОИХ путях разбора ответа.** После первого пасса
  improve в `ru` снова появилось 275 строк с «RU: » — правка стояла только в ветке `n === 1`
  (одиночная строка), а батч из 5 шёл через общий цикл `parseResponse`. Проверено 2026-11-23.
  Что делать: тест на эхо — для батча, а не только для одиночной строки.

- ⚠️ **Утечка спикера бывает без двоеточия: «(голос Зои)».** Основной шаблон ждал
  `(говорит|speaker|эмоция):`, поэтому такая метка уехала в текст. Ловится `VOICE_TAIL_RX`
  (в конце строки, короткая), но с исключением «Голосовой файл» — иначе режется живой текст
  (`Каллиах Недоступен (Голосовой файл)`). Проверено 2026-11-23.

- ✅ **Пасс improve принимается по замеру, а не на глаз.** 415 помеченных судьёй строк →
  переписано 315 → пере-суд тех же ключей → 85 откатов (остались плохими) → итог 164 правки,
  из которых 116 судья признал «ок». Заготовка приёмки — `tmp/improve_verdict.mts`
  (сравнение двух `.jsonl` + откат из копии PO).

- ⚠️ **Не писать регексы через `python - <<'PY'` / shell-heredoc.** `\b` превращается в
  символ backspace (0x08) и регулярка молча мертва (`/anal<BS>/i` не матчит «Anal»).
  Трижды поймано 2026-11-23. Что делать: регексы — через `edit`/`write`, а после правки
  проверять `od -c` или прямой прогон, который должен матчить.

- ✅ **Лексикон регистра откалиброван на корпусе.** Первый прогон дал 287 «смягчений» и
  19 «клиники» — из них верных единицы: `fuck` как междометие законно переводится «чёрт/бля»,
  «Vaginal Sex» — это название статы, клиника есть и в источнике. После уточнения
  (fuck только как сексуальный глагол; падежи «сисек/зада/кисок/попе»; клиника не флагуется,
  если термин есть в EN-оригинале) осталось **27 «смягчений» и 2 «клиники»** — это список,
  который реально читается глазами, а не 300 черновиков.
