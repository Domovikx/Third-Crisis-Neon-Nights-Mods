# MAP — translate-local (факты и грабли)

Инструмент — Python-легаси (порт: `tasks/2026-11-21-port-qa-and-translate.md`).
Проверено 2026-11-21 на текущем `po/` (ru 18 596/33 271, de/pl по 11 155).

## Готчи

- ⚠️ **Валидация резала длинные переводы** → `validate()` отбрасывал
  `len(tr) > len(src) * 2.5 + 20` («too long»), что противоречит правилу
  репозитория «длина не критерий» (AGENTS.md) → проверено: проверка удалена,
  тест `validate no length limit` зелёный → не возвращать лимиты длины ни в
  валидации, ни в QA.

- ⚠️ **`--model trans14` — не имя модели, а идентификатор загрузки LM Studio** →
  `lms load … --identifier trans14`; при другом идентификаторе сервер ответит
  «model not found» → проверено прошлыми прогонами (RUNBOOK в SKILL.md) →
  перед батчем сверять `curl 127.0.0.1:1234/v1/models` и передавать `--model`.

- ⚠️ **Запись po была неатомарной** → `set_msgstr_inplace` делал
  `path.write_text`, обрыв мог обнулить файл → проверено: добавлен
  `.part` → replace, тест «inplace atomic, no .part» → правило репозитория
  (атомарная запись) теперь соблюдено и здесь.

- ⚠️ **Импорт `po_file` — Python-модуль, не `.mts`** → `translate_local.py`
  делает `sys.path.insert` в `extract-text/scripts` и `import po_file` →
  проверено чтением кода → удаление `po_file.py` до порта сломает
  translate-local; при порте переключить импорт на `.mts`.

- ⚠️ **Правила языка только для ru/de/pl** → `translates/<code>.md` есть у трёх
  языков; для остальных 8 печатается «generic mode» → проверено: скрипт
  предупреждает, но переводит generic-промптом → не ждать от ja/zh/ko
  качества без файла языка; задача `tasks/2026-11-21-translates-language-packs.md`.

- ⚠️ **`--include` фильтрует по тексту/контексту, не по ассету** → в POT нет
  `#:` refs, поэтому фильтра по сцене нет (нужен `find_source`) → проверено
  чтением кода (`--include` матчит msgid/msgctxt) → не пытаться отобрать
  «только level3» этой опцией.

- ⚠️ **Пауза — файл, а не сигнал** → `tmp/translate-local/PAUSE`; удаляется
  вручную → проверено: цикл проверяет файл перед каждой пачкой, Ctrl+C
  безопасен (запись после пачки) → при зависшем процессе сначала пауза,
  потом разбор лога.
