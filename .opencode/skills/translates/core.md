# core — общие правила перевода (все языки, EN→N, adult visual novel)

Языкозависимое (род, SFX, типографика, глоссарий) — в `<code>.md`.
Здесь только механика, одинаковая для всех языков.

## Единица перевода

Одна реплика/строка за раз. Две одинаковых строки в разных сценах могут
значить разное — контекст 3–5 строк вокруг обязателен.

## Что переводить, что нет

- Переводится всё читаемое: диалоги, наррация, UI, выборы, SFX, имена.
- Copy-through (как есть): арт-код и паттерны (`AfN6A`, `$TA`, `C?j`),
  CamelCase-идентификаторы (`RestrictSaves`), шейдерные проперти (`_Albedo`),
  пути/расширения (`.wav`, `path_id=`), чистые числа/версии, одиночные
  символы, уже-переведённое.
- Mixed strings: код оставить, английскую часть перевести
  (`handlesOut must be the same size as ...` → перевести фразу, код цел).
- **Бренды, торговые названия и аббревиатуры — латиницей**: `CUM`, `CLIT`,
  `Smutgram`, `Pocket Pussy`, `Neon-Trust`. Это не слова для перевода, а имена:
  «Пей CUM» остаётся с латинским брендом (иначе реклама в игре теряет смысл).
- **Заглушки пола запрещены.** Никогда не писать `говорил(а)`, `рад(а)`, `должен(а)`:
  пол берётся из подсказки (`speaker: Zoey, female`), а если пола нет — фраза
  перестраивается без рода («мне пришлось», «придётся»). Замер 2026-11-23:
  12 таких заглушек доехали до игры и видны игроку.

## Теги и форматирование

- Unity rich-теги (`<color>`, `<font>`) — структуру байт-в-байт, перевести
  только текст внутри. Теги не выдумывать и не ронять.
- **Параметры тегов не переводить.** `<color=perversion>` остаётся `<color=perversion>`,
  а не `<color=извращение>`: имя параметра — идентификатор для движка. Ломается молча:
  цвет просто перестаёт применяться (поймано 2026-11-23 на `<color=пerversия>`).
- Рантайм-fallback: `rich_translation` > `translation` > `rich_text` > `text`.
- Звёздочки `*текст*` (шёпот/мысль), тильда и многоточие (паузы, дыхание) —
  сохранять и адаптировать, не выкидывать.
- Zalgo/glitch: паттерн комбинирующих символов повторить на переводе
  (на каждую букву тот же набор); не добавлять, если не было в оригинале.

## Адаптация под диалоговое окно

- Одна реплика = одна строка. Не склеивать, не разрывать.
- Эллипсис: опускать ясное из контекста. Восклицания сохраняют энергию.
- Ремарки в скобках можно опустить, если эмоция понятна.
- Narration (без speaker): литературный стиль, настоящее время, без рода.
- Choice (выбор игрока): коротко, императив, ~25–30 символов.
- UI: коротко, ~30–35 символов.

## Ревью (после каждой строки и по файлу)

- Всё читаемое переведено? Теги целы? SFX как звуки, не слова?
- Род/обращение по разделу языка. Имена и термины по глоссарию.
- Copy-through помечен/совпадает. Zalgo воспроизведён, если был.
- Естественность: не калька, порядок слов родной, идиомы адаптированы.
