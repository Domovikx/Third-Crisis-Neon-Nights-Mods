# translates — особенности языков (по файлу на язык)

Чтобы не плодить скиллы под N языков: один скилл, внутри файлы.
SKILL.md — только роутер (что где лежит); правила — в файлах, потому что
роутер грузится целиком при каждом discovery, а контент — только когда нужен.

- `core.md` — общие правила всех языков (механика, copy-through, теги,
  залго, ревью). Читает `translate-local` напрямую (single source).
- `<code>.md` (`ru`, `de`, `pl`, ...) — только отличия языка (обращение/род,
  SFX, типографика, глоссарий). `translate-local` подхватывает
  `<!-- PROMPT-START -->...<!-- PROMPT-END -->` блок в запрос.
  Нет файла — generic-режим с предупреждением.
- `ru.md` — полная RU-специфика (мигрировано из удалённого скилла
  `do-translate-game`, история в git). Живые таблицы `### 3.`/`### 9.`
  тянет `translate-local` — нумерацию не менять.
- `de.md`, `pl.md` — DRAFT, перед батчами смотрит переводчик.
- Новый язык: скопировать структуру любого файла, заполнить, статус DRAFT.
  Правит только переводчик, только свой файл.

## Вебсерч при сомнениях (порог — выше среднего)

Лезть в интернет только когда цена ошибки высокая, а уверенности нет.
Можно: существует ли междометие/SFX в языке, регистр сленга, норма
транслитерации имени, типографическая норма. Нельзя: базовая грамматика,
очевидные переводы, всё покрытое файлами — решать самому, спорное
помечать на ревьюеровку.
Правило большого пальца: если неверный выбор уедет игрокам (глоссарий,
SFX-таблица, banned-кластеры) — серчить; если микровыбор стиля — решить
и пометить на ревью.
