# local-dash — дашборд прогресса переводов

Одна страница, read-only (кроме счётчика скорости), без зависимостей:

```bash
node .opencode/skills/local-dash/dashboard.mts          # http://127.0.0.1:8088
node .opencode/skills/local-dash/dashboard.mts --port 8090
```

Показывает:

- **прогон**: идёт / пауза (`tmp/translate-local/PAUSE`) / не запущен, позиция `pos/total`, скорость (строк/мин по дельте между запросами) и ETA;
- **языки**: переведено / пусто / skip / готовность — из `po/*.po`, порядок из `config/language-priority.json`;
- **POT**: записей, skip по правилам, починенные обрывки, вырезано политикой;
- **спорное**: последние `UNPARSABLE/BANNED/LEAK` из `tmp/translate-local/ru.review`;
- **модель и GPU**: `lms ps` + `nvidia-smi` (если есть), RAM;
- **хвост лога** `tmp/translate-local/run.out`.

Источники — существующие артефакты, своих счётчиков не заводит: цифры совпадают с `po/` и логом.

## Грабли

- Скорость считается по двум замерам страницы, поэтому сразу после открытия показывает «—».
  Перезапуск прогона (позиция уменьшилась) сбрасывает счётчик.
- Порт по умолчанию 8088: 8087 занят дашбордом соседнего проекта (TSSR).
- `lms ps` и `nvidia-smi` опрашиваются синхронно (~0.5-1 с); если их нет в PATH, поля пустые.
