# Рефы для озвучки

Здесь живут заготовки голосов и выбранные рефы. Источник истины по персонажам —
`config/voice-characters.mts`, требования к аудио — `docs/voice-refs.md`.

```
voice-refs/<Character>/
  candidates/   # заготовки A/B/C (probe — контрольный)
  chosen/       # выбранный реф; заполняет владелец вручную
```

## Правила рефа (кратко)

- **Длительность 5–30 с**, практический выбор — **15–18 с (вариант B)**:
  официальный диапазон середины, тембра уже достаточно, разброс просодии меньше,
  чем у 20–25 с. A (10–12 с) — контроль «как в TSSR», C (20–25 с) — проверка
  «даёт ли длина больше тембра».
- **Формат**: WAV/FLAC/MP3/OGG; модель сама приводит к 16 кГц mono. Наши файлы —
  WAV PCM 16 бит, 24 кГц, mono.
- **Все варианты одного персонажа — из одной сцены и одного тракта.** Иначе
  сравнение A/B/C измеряет разницу сцен, а не длину.
- **Чистота важнее длины**: без музыки и посторонних голосов; денойзер VoxCPM2
  не включаем (наши рефы уже вычищены).
- **Речь, а не дыхание/стон**: у Rosie в оригинале только тейки дыхания, поэтому
  её `probe.wav` — контрольный образец, а не кандидат для клонирования.
- **Narrator — тот же актёр, другой тон.** Отдельного голоса рассказчика в игре
  нет: мысли Зои в четырёх озвученных сценах читает её же актриса. Поэтому рефы
  `Narrator/` собраны **только из клипов-мыслей** (строки в скобках), а не из
  реплик: клонируем тон наблюдения, а не диалоговую подачу.
- Обработка заготовок: `highpass=f=60, afftdn=nr=15, deesser=i=0.5,
highshelf=f=8000:g=-6`, фейды 30 мс, склейка через паузу 150 мс, `loudnorm`
  −16 LUFS / TP −1.5 dB. Состав каждого файла — `voice-demo/refs-ready/index.md`.

## Выбор рефа

`chosen/` заполняется **вручную**: владелец прослушивает `candidates/`, кладёт
лучший файл в `chosen/` и прописывает путь в `refs.chosen` своего персонажа в
`config/voice-characters.mts`. Пока `chosen` равен `null`, персонаж считается
неготовым к генерации.

## Статус проверки

- У всех кандидатов `manualCheck: "pending"` — **ни один реф ещё не проверен
  ухом**. Акустика (SNR, F0, доля вокализации) посчитана, но тембр и музыка в
  фоне — только на слух.
- **Из текущих заготовок как отправная годится только Zoey** (самый чистый
  источник, три несмежных варианта). Max и Lio — рабочие, но требуют проверки;
  Nova — сначала сверить, тот ли это голос, что в клипе 2,04 с; Rosie — не речь;
  Narrator — тот же актёр, что у Зои, поэтому проверять отдельно: тон наблюдения
  должен отличаться от реплик Зои.
- Заготовки — **не приговор**: любой кандидат может быть забракован, заменён или
  пересобран. Вариант C не обязан быть лучше B, а B — лучше A.

## Git

Аудио в `voice-refs/` **не коммитится** (`.gitignore`). В git попадают только
этот README и структура папок (`.gitkeep`). Чтобы сохранить конкретный реф в
истории, добавляйте его принудительно (`git add -f`).
